# SPIDER Social

A static, multi-page social network-style website inspired by the feed, stories, network, messages, profile, and offers patterns of modern platforms.

## Pages
- `index.html` — home
- `feed.html` — post feed
- `stories.html` — short-form stories
- `network.html` — connection graph
- `offers.html` — opportunities / offers
- `messages.html` — inbox
- `profile.html` — profile page
- `404.html` — custom not-found page
- `_headers` — Cloudflare Pages headers
- `style.css` — shared styling
- `app.js` — shared interactions

## Deploy to Cloudflare Pages
1. Put the files in the repo root.
2. Connect the repo in Cloudflare Pages.
3. Build command: none.
4. Output directory: `/`.
5. Deploy.
